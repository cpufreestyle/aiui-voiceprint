# 开发记录：声纹录入语音向导

- **项目**：aiui-voiceprint（Rokid Glasses 声纹应用 · 听障助手）
- **日期**：2026-07-17
- **相关文件**：`pages/enroll/enroll.ink`、`pages/index/index.ink`、`utils/active-user.js`、`utils/tts.js`、`utils/gesture.js`

---

## 1. 需求（用户原话拆解）

把声纹录入过程做成**语音+视觉引导的向导**，流程：

1. 开始声纹录入，录入第一句；
2. "跟我一起念"，念完一个例句；
3. "三二一"倒计时，跟着念；
4. 念完进入第二个例句；
5. 例句念完进行声纹录入；
6. 录入注册完成后，进入下一步，确认是否**启用**声纹；
7. 声纹库可有多个声纹，可**来回切换**。

**确认的关键决策**：
- 录音推进方式 = **全自动流转**（倒计时→录音→自动进下一句，全程基本不用操作）；
- "启用声纹" = **当前身份标识**（主页显示"当前：XXX"，可切换；不改验证的 1:N 逻辑）；
- 原手动按钮 = **向导为主 + 保留手动兜底**（折叠在"手动模式（高级）"里）。

## 2. 实现

### 2.1 新增 `utils/active-user.js`
当前启用身份管理。声纹库结构扩展为 `{ users:[...], activeUserId:'user_xxx' }`。
- `getActiveUser()` / `setActiveUser(id)` / `clearActiveUser()` / `reconcileActiveUser()`（删除用户后校正悬空引用）；
- 同步写 `globalData.currentUser`。

### 2.2 改写 `pages/enroll/enroll.ink` — 向导状态机
`wizardStep`：`intro → prompt → countdown → recording → checkok → (循环) → enrolling → activate → done`。
- 每步 = 大字幕文案 + 语音播报 + 自动/单键推进；
- 三二一倒计时（大数字 + 语音 + 震动）；
- 录音复用 `recording-session.js`（3 秒自动停），向导下**自动保存样本并推进**，无需点"保存"；
- 录不清晰 → "没听清，再念一次"重录当前句；
- 生成失败 → 退回 intro，点一下重新开始；
- 注册末尾问"是否设为当前身份"（点=启用 / 双击=以后再说）；
- 入库逻辑抽为 `persistVoiceprint()`，向导与手动共用；
- 保留手动模式按钮组作兜底。

### 2.3 改 `pages/index/index.ink` — 多声纹切换
- 状态卡新增"当前身份"行；
- 声纹列表每张卡可点击切换启用，当前身份高亮 +「当前」标记；
- 删除当前身份后自动清空启用标记（`reconcileActiveUser`）。

## 3. 用户反馈的两个问题及处理

### 问题 1：没有语音引导
- **原因**：仿真器**没有实现** `wx.getSpeechSynthesizer`，`tts.js` 设计为"无能力时静默"，所以仿真里听不到语音。
- **核实**：已查 AIUI 官方文档，确认 `wx.getSpeechSynthesizer()` 是**正确的 API 名** → **真机上语音会正常发声**，仿真静默属预期。
- **应对**：向导做成**视觉优先**（倒计时大数字、例句、字幕都在动），无语音也能跟。

### 问题 2：提示词一出现就直接退出（闪退）★真 Bug，已修
- **根因链**：
  1. `gesture.js` 把所有"返回类"按键（Backspace/Escape/**KEYCODE_BACK**/镜腿双击 202 等）直接路由到 `handleDoubleTap`；
  2. enroll 的 `handleDoubleTap` 在向导进行中会 `cancelEnroll() → safeBack()`，**直接把整页弹出**；
  3. 又因仿真无语音、用户不知会自动流转，**手动按键/双击想推进** → 那一下被当成"返回" → 退出。
- **修复**（`enroll.ink`）：
  - 新增 `cancelWizard()`：向导中双击/返回 = **停录音、回起始步、不退出页面**；
  - `handleDoubleTap` 增加 `if (this.data.wizardActive) return this.cancelWizard()` 保护；
  - `_skipNextStop` 标记：取消向导时跳过紧接着的自动 stop 回调，避免误处理；
  - 字幕强化"点一下开始后无需再操作 / 录完自动进入下一句（无需按键）"，减少误触。
