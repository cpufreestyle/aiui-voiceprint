Three Load-Bearing Chains

三支柱：能力链的核心命题

每条链承载一个判断，而非一份功能清单

用例 一

语音路由：AGENTS.md 穷举 + intent-router 兜底

AGENTS.md 用触发说法穷举「让 OS 认得我们」，应用内 intent-router.js 正则兜底「不赌 OS 传参」——OS 传不传结构化参数是未决项（见 §8），路由必须两头都能落地。

证据：utils/intent-router.js 正则表 9 组样例实跑全 PASS；MODE_PAGE 四路径已与 pages/ 实际文件逐一核对无断链。
用例 二

图形识别：零新文件，一个入口参数化

不新增页面文件，只在 vision.js 加一个结构化 prompt 入口 describeShape，与 describeImage 共用同一条请求/降级路径，不复制逻辑。改动最小、性价比最高、可独立交付。

证据：vision.js 实测 describeShape 与 describeImage 共用同一 requestImageDescription 内部函数，仅 prompt 参数不同。
用例 三

生成发手机：重量在云端，不在眼镜端

眼镜端只做「拍照 + 两次 wx.request + 显示取件码」；真正的工程量是云端 relay、手机 H5 结果页、图生图 API 三个外部组件——这才是本方案唯一需要「新建服务」的部分。

证据：genimg.ink 仅编排 4 个已有 utils 模块调用，无新增业务逻辑；relay 独立 FastAPI 服务，7/7 端点已现场验证。

Verified Judgments

多宝阁：六条判定与证据

每格一条判断，角标标注属实程度——不是罗列，是核对

一 无自定义热词 属实 ⚠约束

app.json 仅 pages / window / permissions 三字段，无 intent/skill 字段；唤醒词固定「Hi Rokid」，第三方无法注册热词——这是本方案一切设计的起点约束，不是可协商项。

二 路由页面路径零断链 ✅属实

MODE_PAGE 四路径 caption/shape/genimg/home 与 pages/ 下实际文件逐一核对匹配。

三 relay 真实可用 ✅属实

本次现场对 8262 端口实跑：health/push/pull/r/qr 全 200，非4位码 400，过期码经 ok:false 正确拒绝（非字面 HTTP 404，语义等价）——7/7 通过。

四 眼镜端不可真机验证 ↓诚实降级

wx.* / session.prompt() / 相机 仅 Rokid QuickJS 运行时提供，本机开发环境只能做语法/结构/样例校验，无法跑真机（对应 §8 未决项 1-3）。

五 三处待配置才转 live ⚠部分

视觉网关 apiKey、图像生成 API key、relay 公网地址三处配置缺一，未配一律降级为演示文案，不假装成功。

六 跨文件引用一致 ✅属实

genimg.ink 从 imagegen.js 导入 4 个 + phone-bridge.js 导入 6 个，共 10 个函数，与两文件 export 声明逐一匹配，无断链。

Open Questions

未决项：需向 Rokid 官方/实机确认

8 条待验证，标 hl 为影响面最大的三条

01语义路由粒度重点

智能体商店路由能否「带参数唤起指定模式」，还是只能唤起 Agent 并透传原始话语？本方案按后者（最坏情形）设计。验证法：发含新 AGENTS.md 的测试包，实机说三类指令，log 打印完整 onLaunch options JSON。

02options.query 真实字段名与结构重点

query 是 string 还是 object？键名是 query/text/utterance 中哪个？onShow 热启动是否重复携带？app.js 已做多候选容错，需实机 log 定死后删冗余分支。

03redirectTo 在 onLaunch 的时序

onLaunch 内立即跳页在该 QuickJS 运行时是否稳定，已用 setTimeout(0) + globalData 双保险，需实测是否够。

04路由匹配率与技能描述迭代

AGENTS.md 触发说法覆盖不足会导致「Hi Rokid 听懂了但没派给我们」；上架后需按真实 miss 语料迭代，确认商店更新 AGENTS.md 的审核与生效周期。

05图像生成供应商与成本/合规重点

Agnes 网关是否开放 OpenAI 兼容 images 图生图端点未证实，若否需另选供应商；单张成本 × 调用量，以及生成内容合规责任（用户拍到人脸/敏感物再生成的边界）需立项前定。

06relay 合规与运维

中转图片即使短 TTL 也属用户内容存储，需明确隐私声明、部署地域、HTTPS 证书与限流；4 位取件码防遍历参数（TTL/次数）要压测定值。

07wx image 组件加载外网图片

relay 代画二维码方案依赖端上 <image> 能加载 https 网络图，需实机验证；不行则直接走纯数字取件码兜底。

08session.prompt() 可用性与延迟

端上 LLM 在本机型的注入情况、首 token 延迟，决定 intent-router 的二级 LLM 兜底是否值得保留。
